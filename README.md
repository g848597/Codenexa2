# Снежана Утешева — сайт-визитка с онлайн-записью

Лёгкий mobile-first сайт на чистых **HTML / CSS / JavaScript**, без Node.js, без backend и без базы данных.
Все записи сохраняются в `localStorage` браузера пользователя.

## Структура файлов

```
index.html      — главная страница
style.css       — все стили
script.js       — вся логика: услуги, портфолио, календарь, запись, localStorage
admin.html      — демо-панель для просмотра записей
assets/         — фотографии (сгенерированы как элегантные плейсхолдеры)
README.md       — этот файл
```

## 1. Как открыть сайт локально

Просто дважды кликните на `index.html` — он откроется в браузере.
Либо, для более корректной работы кириллицы/шрифтов, запустите локальный сервер:

```bash
# Python
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## 2. Как загрузить на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него все файлы этого проекта (`index.html`, `style.css`, `script.js`, `admin.html`, `assets/`).
3. В настройках репозитория откройте **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` и папку `/root`.
5. Сохраните — через минуту сайт будет доступен по адресу вида `https://username.github.io/repo-name/`.

Сайт точно так же работает на Netlify, Vercel (как статический проект) и Cloudflare Pages — просто загрузите папку целиком, сборка не требуется.

## 3. Как изменить имя мастера

Откройте `script.js`, найдите блок `BUSINESS_CONFIG` в самом начале файла:

```js
const BUSINESS_CONFIG = {
  masterName: "Снежана Утешева",
  ...
};
```

Также замените имя в `index.html` (в `<title>`, хедере, hero-секции, футере) и в `admin.html`.

## 4. Как изменить цены и услуги

В `script.js` найдите массив `SERVICES`. Каждая услуга — объект:

```js
{
  id: "lash-lamination",
  name: "Ламинирование ресниц",
  desc: "Изгиб, объём и питание собственных ресниц",
  price: 8500,       // цена в тенге
  duration: 60,       // длительность в минутах — используется календарём для расчёта занятости
  img: "assets/service-lash-lam.jpg"
}
```

Можно менять цены, названия, добавлять или удалять услуги — карточки на сайте и в форме записи обновятся автоматически.

## 5. Как изменить номер WhatsApp

В `script.js`, в `BUSINESS_CONFIG`:

```js
whatsapp: "77000000000", // только цифры, международный формат, без «+»
```

## 6. Как изменить Instagram

В `script.js`:

```js
instagram: "https://instagram.com/ваш_логин",
```

И обновите ссылку `href="https://instagram.com/"` в `index.html` (в мобильном меню и в разделе «Контакты»).

## 7. Как изменить рабочие часы

В `script.js`, в `BUSINESS_CONFIG.workingHours` (ключи — дни недели, 0 = воскресенье, 1 = понедельник и т.д.):

```js
workingHours: {
  1: { start: "09:00", end: "19:00" }, // Пн
  ...
  6: { start: "10:00", end: "16:00" }, // Сб
  0: null                              // Вс — выходной
}
```

`slotInterval` задаёт шаг сетки времени (по умолчанию 30 минут).

Чтобы вручную заблокировать конкретный интервал (например, обеденный перерыв или отпуск), добавьте запись в `blockedSlots`:

```js
blockedSlots: [
  { date: "2026-08-15", start: "13:00", end: "14:00" }
]
```

## 8. Как добавить/заменить фотографии

Все фотографии лежат в папке `assets/` и сейчас представляют собой аккуратные абстрактные плейсхолдеры в фирменной палитре (чтобы сайт выглядел завершённым уже сейчас).

Чтобы поставить реальные фото, просто замените файлы с теми же именами:

```
assets/hero.jpg              — главное фото на первом экране
assets/master.jpg            — портрет мастера в разделе «О мастере»
assets/service-*.jpg         — фото для карточек услуг (6 файлов)
assets/portfolio-1..6.jpg    — работы в портфолио
assets/brows-1.jpg / brows-2.jpg / lashes-1.jpg / lashes-2.jpg — дополнительные фото
```

Рекомендуемый размер: около 900–1200 px по длинной стороне, формат JPG, оптимизированный (до ~200–300 КБ на файл), чтобы сайт оставался быстрым.

## 9. Где находятся записи (localStorage)

Все записи хранятся в браузере клиента под ключом `snezhana_bookings`. Посмотреть их можно:

- через `admin.html` — открыть `/admin.html` рядом с сайтом (удобная таблица со статистикой, отменой и удалением записей);
- либо через консоль браузера: `localStorage.getItem("snezhana_bookings")`.

**Важно:** это demo-хранилище на стороне браузера. Разные посетители видят только свои собственные записи (localStorage не общий), а сама владелица бизнеса тоже видит только записи, сделанные в её браузере. Для реального рабочего расписания на этапе роста нужен настоящий backend (см. пункт 10).

## 10. Как позже подключить настоящий backend

Логика записи уже вынесена в отдельные функции в `script.js`:

- `getBookings()` — получить список записей;
- `saveBooking(booking)` — сохранить новую запись;
- `generateSlotsForDate(date, duration)` — рассчитать свободные слоты.

Чтобы перейти на реальный backend (например, свой API, Google Sheets, Airtable или готовый сервис бронирования), нужно будет заменить содержимое этих трёх функций на `fetch()`-запросы к серверу — остальной интерфейс (календарь, шаги записи, подтверждение) менять не придётся.

## Технические требования

- Никакого Node.js, npm, React, Vue, backend-сервера или базы данных.
- Только HTML5 + CSS3 + Vanilla JS.
- Единственная внешняя зависимость — шрифты Google Fonts (Cormorant Garamond + Manrope), подключены через CDN. Если нужна работа полностью офлайн/без внешних зависимостей — удалите ссылки на fonts.googleapis.com из `<head>` в `index.html`, сайт продолжит работать на системных шрифтах.
